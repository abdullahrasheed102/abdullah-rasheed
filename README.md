# Muhammad Abdullah Rasheed — Portfolio

A static, responsive React and Vite portfolio. Update `client/src/data/portfolio.js` to edit experience, project, skill, and contact content. The downloadable resume is in `client/public/resume.pdf`.

## Run locally

```sh
npm install --prefix client
npm run dev
```

The development site runs at `http://localhost:5173`.

Build for static hosting with `npm run build`; the output is written to `client/dist`. Preview the production build locally with `npm run preview`.
